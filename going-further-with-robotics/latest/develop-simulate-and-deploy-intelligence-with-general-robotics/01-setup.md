# Setup[#](#setup "Link to this heading")

## Prerequisites[#](#prerequisites "Link to this heading")

Basic knowledge of NVIDIA Isaac Sim, robotics fundamentals, and Python.

## Account Creation / Login[#](#account-creation-login "Link to this heading")

1. Visit [https://grid.generalrobotics.dev/](https://grid.generalrobotics.dev) and create an account.
   You can use your Google/GitHub accounts for single sign-on, or set up an account using an email address and password.
2. You will receive a verification email upon sign up, and once you verify your email through the link within, you will have access to the platform.

### Software Requirements[#](#software-requirements "Link to this heading")

Because Open GRID runs remotely and is accessed through a web browser, the setup is very simple. Open GRID is optimized for performance on Chrome and Edge web browsers.
