# Getting Started With Digital Twin Scene Assembly[#](#getting-started-with-digital-twin-scene-assembly "Link to this heading")

Welcome to **Assembling Digital Twins With Omniverse and OpenUSD**. This course establishes the foundation for building simulation-ready digital twins of industrial facilities using NVIDIA Omniverse and OpenUSD.

Before you can assemble complex factory scenes, you need to understand the tools, file formats, and organizational practices that make digital twin projects successful. This course guides you through setting up your Omniverse environment, understanding how OpenUSD structures 3D data, and organizing assets in ways that scale from simple demonstrations to production-scale facility models.

## Learning Objectives[#](#learning-objectives "Link to this heading")

4. **Validate USD assets and troubleshoot common issues** using Asset Validator and diagnostic tools.
