## ROS[#](#ros "Link to this heading")

The Robot Operating System (ROS) is a set of open-source software libraries and tools created to build robot applications.

NVIDIA is committed to supporting the ROS community, bringing accelerated computing, generative AI and simulation advances to ROS developers worldwide. NVIDIA is a supporter of Open Robotics, the umbrella organization for OSRF and all its initiatives including ROS.
